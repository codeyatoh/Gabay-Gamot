# Landing Page Plan

## Goal

Create a clean, trustworthy landing page that explains what GabayGamot does before building the full web app.

## Suggested Sections

1. Hero
2. Problem
3. Solution
4. Core Features
5. How It Works
6. User Roles
7. Benefits
8. Technology
9. Final Call To Action

## UI Direction

- Modern minimalist healthcare interface
- White or very light background with slate/neutral text
- Green/teal as the primary accent, with small blue/cyan support accents
- Use Shadcn UI components as primitives, not generic prebuilt blocks
- Build custom section compositions for GabayGamot
- Use polished product-style visuals, such as inventory previews, OCR scan panels, referral cards, and AI recommendation cards
- Add subtle animations for section reveals, hover states, tab changes, and dashboard preview interactions
- Avoid overly decorative layouts, generic SaaS hero sections, and repeated card grids
- Make the page feel practical, reliable, aesthetic, responsive, and easy to understand

## Animation Notes

- Use smooth fade and slight slide-up reveals
- Use subtle staggered animations for feature groups
- Use calm hover animations on interactive cards and buttons
- Keep interaction animations around 150ms to 300ms
- Keep section reveal animations around 500ms to 700ms
- Avoid bouncy, flashy, or distracting motion

## Main CTA Ideas

- Get Started
- Login
- Request Access
