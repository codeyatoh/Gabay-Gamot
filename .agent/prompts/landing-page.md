# Landing Page Prompt

Use this prompt when working on the GabayGamot landing page.

```text
You are helping build the GabayGamot landing page.

Use the files in .agent/ as project context.

Goal:
Create a clean, trustworthy, beginner-friendly landing page for GabayGamot, a web-based medicine inventory, dispensing, monitoring, and referral system for barangay health centers.

Use:
- React with Vite
- Tailwind CSS
- Shadcn UI components
- Shadcn UI as primitives, not generic final blocks
- lucide-react icons
- Modern minimalist healthcare dashboard style
- Green/teal accents
- Subtle polished animations

Landing page sections:
- Hero
- Problem
- Solution
- Core Features
- How It Works
- User Roles
- Benefits
- Technology
- Final CTA

Visual direction:
- custom GabayGamot product visuals
- inventory dashboard preview
- OCR scan preview
- expiry alert or stock status panel
- referral flow preview
- AI recommendation card

Animation direction:
- fade and slide-up section reveals
- soft hover scale on interactive cards
- subtle staggered entrance for feature groups
- smooth transitions under 300ms for interactions

Avoid:
- generic SaaS hero sections
- repeated default Shadcn card grids
- excessive gradients
- random decorative shapes
- flashy or bouncy animations

Keep the UI practical, clear, responsive, aesthetic, and easy to understand.
```
