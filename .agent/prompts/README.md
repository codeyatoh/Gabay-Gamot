# Agent Prompts

Reusable prompts for working on GabayGamot.

Keep prompts short and focused. Use the planning files in `.agent/` as the source of truth.

## Available Prompts

- `landing-page.md` - for improving or building the landing page
- `frontend.md` - for React, Tailwind, and Shadcn UI work
- `backend.md` - for future Node.js and Express API work
- `firebase.md` - for future Firebase Auth and Firestore work
